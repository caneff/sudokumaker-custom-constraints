# The class of every shared test, for `tests/all.sh --changed`: one per line,
#
#   <file under examples/_shared/> tree  <what it reads outside shared example code>
#
# A `tree` test is a tree check: it reads the tree rather than shared example
# code (a file under finders/, every tracked script, the gate's own wiring,
# the layout of the examples), and it runs on every narrowed run, beside lint.
# A `code` test is a shared example-code test: it reads nothing under
# finders/, and a diff lying wholly inside finders skips it. A shared test
# with no line here runs on every narrowed run, and
# examples/_shared/seam_runner.test.py fails until it has one.
examples/_shared/gate.test.py tree  reads every finder test file and checks that the gate runs it
examples/_shared/seam_runner.test.py tree  scans finders/ for reads of another unit's directory
