# The tests that cannot run in Pants's sandbox (tests/pants_prelude.py), one
# per line:
#
#   <test file> <reason, quoting what failed in the sandbox>
#
# An entry stays on the seam runner's own loop for good, and is run on every
# narrowed run: Pants selects every other suite. examples/_shared/gate.test.py
# checks this list: every test file of the seam is wired into Pants or named
# here, never both, and an entry with no reason fails it.
#
# npm packages: pants.toml keeps node_modules out of every sandbox, and Node
# resolves an ES module import from no other place.
examples/_shared/app-session.test.mjs the Chromium session never starts: `Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'playwright' imported from examples/_shared/app-session.mjs`
examples/_shared/app-solve-lib.test.mjs it starts app-solve.mjs, which stops on the same import: `Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'playwright' imported from examples/_shared/app-session.mjs`
examples/_shared/bundle-index.test.mjs `Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'acorn' imported from examples/_shared/bundle-index.mjs`
examples/_shared/spec_649_closing.test.py it copies the nearest node_modules directory and finds none: `StopIteration` from `next(d / "node_modules" for d in (ROOT, *ROOT.parents) if (d / "node_modules").is_dir())`
#
# git: `//:tree` leaves `.git` out of every sandbox, so a suite that asks git
# for the tracked files has no repository there.
examples/_shared/bundle-load.test.mjs `git grep` finds no repository: `fatal: not a git repository (or any of the parent directories): .git`
examples/_shared/spec_809_closing.test.py it lists the tracked tree to copy it: `AssertionError: git ('ls-files', '-z') failed in the copy:` `fatal: not a git repository (or any of the parent directories): .git`
examples/_shared/sudoku_kit_source.test.py `git ls-files` finds no repository: `subprocess.CalledProcessError: Command '['git', 'ls-files', '-z', '--', '*.py']' returned non-zero exit status 128`
