## Mask conventions

A digit mask is a bitmask where bit `d` represents digit `d` (`1 << d`). `allDigitsMask = (1 << (maxDigit + 1)) - (1 << minDigit)`. There is no cell-set mask type: a set of cells is always a plain array or `Set` of cell ids, never a bitmask.
