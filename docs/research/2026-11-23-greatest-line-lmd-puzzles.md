# Greatest Line puzzles on Logic Masters Deutschland

Candidate real-world boards for timing a Greatest Line component
(`just time`). Searched 2026-11-23 via web search and the LMD puzzle pages;
LMD's own search form did not accept scripted queries, so this list is not
exhaustive.

The rule (Dorlir, a.k.a. Prof.Dori, who invented it): "On each line, there is
exactly one cell whose value is greater than the sum of any other two cells on
that line."

## Seen and set aside

Each changes what a cell's value is, or adds a rule with no SudokuMaker
built-in, so it would time more than the line:

- The Greatest Sum, The Pi Guy, [000UVK](https://logic-masters.de/Raetselportal/Raetsel/zeigen.php?id=000UVK) — box-segment sums on the same lines, negative-constraint X.
- The Greatest Pseudocell, Prof.Dori, [000UE5](https://logic-masters.de/Raetselportal/Raetsel/zeigen.php?id=000UE5) — pseudo cells.
- Greatest Lies, marty_sears, [000VUI](https://logic-masters.de/Raetselportal/Raetsel/zeigen.php?id=000VUI) — liar cells.
- NATMOS 5: Greatest Cypress in Ion, Neokart, [000VON](https://logic-masters.de/Raetselportal/Raetsel/zeigen.php?id=000VON) — Knapp Daneben modifier.
- Greatness within Chaos, PrissyP, [000UFW](https://logic-masters.de/Raetselportal/Raetsel/zeigen.php?id=000UFW) — chaos construction, 6x6.
